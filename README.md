# Coffee Diner

An original, asset-free JavaScript time-management game with diner and barista modes.

## Run
Open `index.html` in a modern browser. No install, build step, network connection, or external dependencies required.

## Play
- Diner: click an empty table to seat a waiting guest; take the order; start its kitchen ticket; serve when ready; collect payment; clear the table.
- Coffee bar: select a guest; add exactly the ingredients shown in their recipe; serve. Ingredient order does not matter; duplicate or extra ingredients count as mistakes.
- Meet the earnings target in each 90-second shift to advance the day. All earnings enter your wallet, even if you miss the target.
- Buy equipment between shifts for faster cooking and more patient guests.
- Pause manually; switching browser tabs automatically pauses. Sound is optional.
- Progress saves locally when browser storage is available. Private browsing or moving the file can affect persistence.

## Implementation
Single HTML file with CSS-drawn characters, tables, and a cup; vanilla JavaScript; optional synthesized Web Audio tones. No third-party art or Diner Dash branding/assets. Responsive pointer controls and native buttons.

## Verification status
Initial prototype; not yet browser-playtested or accessibility-audited. Test both modes, shift completion, upgrades, pause/resume, and saved progress before release.
